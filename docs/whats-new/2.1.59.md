- **Shared project notes.** Every project you're in now has a folder: `Team/<project>/`. Notes, canvases, pictures and PDFs you put there are shared with everyone in that project, on computers and phones.
- **Write together, live.** Open the same note as a teammate and you see their cursor with their name, and their typing as it happens. Canvases update about a second later.
- **Works offline.** Edit without internet; your changes and everyone else's are combined when you're back online.
- **Nothing gets lost.** Deleted shared notes go to a Trash for 30 days, and every note keeps earlier versions. Use the commands **Team notes: Trash** and **Team notes: Version history of this note**.
- Move a note into another project's folder and it's shared with that project instead (you're asked first). Files outside project folders stay private.
- You can turn it off in Settings → Mad Kanban → **Shared project notes**.
