# What's new notes

`<version>.md` here is what the Telegram bot sends to everyone connected when that version is
released (`scripts/release-plugin.sh` puts it on the server as `public/plugin/whats-new.md`).
No file for a version, no message. Keep it to a few short bullets in plain words: what people
can do now, and where to find it. `**bold**` and `` `code` `` work; links don't.
