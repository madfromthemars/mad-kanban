The button does nothing? Copy the link, then in Obsidian go to Settings → Mad Kanban and paste it into Team server join string.

Don't have Mad Kanban on this phone yet?
  1. Install Obsidian from the App Store or Google Play and create a vault.
  2. Settings → Community plugins → turn them on → Browse → install and enable BRAT.
  3. Settings → BRAT → Add beta plugin → type madfromthemars/mad-kanban → Add plugin.
  4. Come back here and tap Open in Obsidian. If the code has expired, make a new one.
